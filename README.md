# Expense Tracker

A simple Python expense-tracking application that stores expenses in a CSV file and generates monthly and category-wise summaries.

## Features

- Add expenses
- Store expense data in CSV format
- View all expenses
- Generate monthly expense summary
- Generate category-wise expense summary
- Display charts using Matplotlib

## Technologies

- Python
- Pandas
- Matplotlib
- CSV

## How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python expense_tracker.py
```

## Menu

1. Add Expense
2. View Expenses
3. Monthly Summary
4. Category Summary
5. Exit

```text
expense-tracker/
```

The `expenses.csv` file is created automatically when the first expense is added.

This project demonstrates Python functions, file handling, CSV data storage, Pandas data analysis, and Matplotlib visualization.
